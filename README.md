# Bazzar App 

Bazzar is a Flutter mobile application for browsing and searching books using the **Google Books API**.

## About The Project

The app allows users to explore books, search for specific books, and view book information through data fetched from the Google Books API.

This project was built to practice Flutter development, API integration, and handling real-world data.

## Features

*  Browse books
*  Search for books
* View book details
*  Fetch book data using Google Books API
*  Responsive Flutter UI

## Technologies

* **Flutter**
* **Dart**
* **Google Books API**
* **REST API**
* **JSON**

## Project Structure

The project is organized to keep the code clean and easy to maintain.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/bazzar_app.git
```

### 2. Navigate to the project

```bash
cd bazzar_app
```

### 3. Get dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```

## API

This project uses the **Google Books API** to retrieve book information.
